## Getting Started

Every project is a standard .NET console app or solution. To open and run any project:

**Prerequisites:** [.NET SDK](https://dotnet.microsoft.com/download) installed

```bash
# Clone the repo
git clone https://github.com/thaisangcr7/C_vitamin.git

# Navigate to any project folder
cd C_vitamin/CSharp_Mini_8hrs/42.\ Classes

# Run the project
dotnet run
```

Or open any `.sln` file directly in **Visual Studio** or **JetBrains Rider**.
